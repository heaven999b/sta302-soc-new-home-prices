# R 与 Python 数值核对（方案一：SOC 新房售价）

> 日期：2026-09-30　|　R 4.4.3（`Part1_Code.Rmd`、`Part2_Analysis.Rmd`）对照 Python 探针（statsmodels 0.14.0；结果文件已复制到本仓库 [`probe/results/`](../probe/results/)：`soc.json`、`soc_fullflow.json`、`soc_extra.json`、`soc_iid.json`、`tables/soc_*_coefficients.csv`）。
> 少数 JSON 里没有保存的量（中心化后的 GVIF、AIC 路径、Box-Cox 精确最优点、ICC），用探针自己的 [`probe/scripts/utils.py`](../probe/scripts/utils.py) 在同一训练集上重新算出（只读探针数据，没有改动探针结果）。
> 全部核对只用**训练集**（4,330 行）和 2024 年独立样本；测试集的 Y 没有被读取或比较。

## 1. 结论

- 共核对 **281 项**（其中 6 项是把一整张系数表或一组检验打包成一行，实际逐个比较的数字约 780 个）。
- **261 项完全一致**：OLS 系数、SE、CI、R²、F、partial F、HC3 Wald、各组斜率/弹性、Cook's D、DFFITS、DFBETAS、GVIF、2024 年复现等，最大相对差 3.3e-10（远小于 1e-6）。
- **其余 20 项的差异都已查明原因**，没有一项是计算错误：
  - 10 项是 BIC/AIC 的**常数差**：R 的 `BIC()` 比 statsmodels 多算一个参数（σ²），恒差 log n = 8.3733；`step()` 用的 `extractAIC()` 省略了似然中的常数，恒差 n(1 + log 2π) = 12,288.008。**BIC 与 AIC 的删变量顺序完全相同。**
  - 3 项是 **Box-Cox 网格精度**：R 用 0.001 网格得 λ̂ = −0.421，Python 用 0.005 网格得 −0.42；两边在同一似然函数上的精确最优点都是 −0.42083。
  - 2 项是**组内 SD 的定义**：Python 用 `np.std`（分母 n），R 用 `sd()`（分母 n−1），SD 比相差 < 0.6%。
  - 2 项是**中西部 1 自由度对比的聚类 SE**：相对差 1.2e-4。原因是 Python 的设计矩阵里多了一列与 division 完全共线的 midwest 主效应，statsmodels 在聚类小样本校正 (N−1)/(N−K) 中把这一列也计入 K；R 的模型不含这一冗余列。**以 R 为准**（结论不变：z 检验 p = 4.38e-8 对 Python 4.39e-8）。
  - 3 项是 R 新增、Python 没有的检查（见第 4 节）。
- 划分与数据：R 清洗得到的 6,185 行与 Python 的 `soc_analysis.csv` 在 ID 顺序和全部预测变量上逐行完全一致；售价只在训练集行上比较，也完全一致。`split_ids.csv` 的 1,855 个测试集 ID 与 `soc_test_ids.csv` 完全一致。

## 2. 差异原因详解

| 差异 | 原因 | 处理 |
|---|---|---|
| BIC 数值 | statsmodels：BIC = −2 logL + log(n)·p；R `BIC()`：−2 logL + log(n)·(p+1)（把 σ² 也算作参数）；R `step(k = log n)` 用 `extractAIC()` = n·log(RSS/n) + log(n)·p，省略常数 n(1 + log 2π) | 三者只差常数，同一数据上比较模型时结论相同；删变量顺序一致 |
| AIC 数值 | 同上，`extractAIC(k = 2)` = statsmodels AIC − n(1 + log 2π) | AIC 都只删 hoa |
| Box-Cox λ̂ 与 CI | `MASS::boxcox()` 只在给定网格上取最大值；Python 先 0.05 粗网格再 0.005 细网格 | Part 2 同时报告网格值与 `optimize()` 的精确值 −0.4208，两边一致 |
| GVIF 定义 | `car::vif()` 用系数估计量的相关矩阵，Python 探针用设计矩阵（去截距）的相关矩阵。两者在数学上等价（det R11·det R22 / det R 对 R 与 R⁻¹ 相同） | 数值完全一致（1.842、2.879、1.882、22.205、2.587），无需处理 |
| 组内残差 SD 比 | Python `np.std` 分母 n；R `sd()` 分母 n−1 | 定义差，结论（约 5 倍）不变 |
| 中西部对比聚类 SE | statsmodels 把一个完全共线（被 pinv 吸收）的列计入小样本校正的 K | 以 R 为准；差异 0.01% |
| 聚类稳健 p 值的参照分布 | statsmodels `cov_type="cluster"` 默认用正态分布（z）；只有 9 个聚类时更合理的是 t(G−1) = t(8) | R 两种都报告：中西部对比 z 检验 p = 4.4e-8，t(8) 检验 p = 5.9e-4（仍 < 0.01） |
| division × fullbath 混杂检查的 HC3 | 西南中部 × “≤1 全卫”只有 1 套房，该点杠杆值 = 1、残差 = 0。R 的 `vcovHC(type = "HC3")` 在这里得到 0/0 = NaN，`lmtest::waldtest()` 也拒绝含别名系数的模型；statsmodels 用伪逆，残差约 1e-15，贡献几乎为 0 | R 中改用自定义的 HC3：杠杆值 = 1 的点对 meat 的贡献记为 0（其他点与标准 HC3 完全相同）。结果与 Python 一致到 1e-11 |

## 3. Python 探针结果中需要更正或补充的地方

数值层面没有发现 Python 算错的地方（除上面聚类 SE 的 K 计数外）。以下是**解读或描述**上的问题，写报告时以本节为准：

1. **“加入 division 固定效应后 ICC ≈ 0”不能作为误差不相关的证据。** 加入 division 后，每个 division 内残差均值被强制为 0，ICC ≈ 0 是机械结果。应改为：不含 division 的模型中残差 ICC = 0.153（Part 1 设定）/ 0.178（最终设定），说明 division 吸收了地区层面的差异；楼盘/建造商层面的相关仍无法检验。
2. **“ENC − SA 的差值稳定在 −0.11 到 −0.16（p ≤ 0.013）”需要加限定。** Python 的“全部替代交互同时加入”只放了 6 个（漏了 division × fullbath）。R 把 7 个全部同时加入后：面积 × division 交互整体仍显著（HC3 p = 1.3e-07），但 ENC − SA 缩小到 -0.089（HC3 p = 0.076），Pacific − SA 变为 0.152（p = 0.018）。更稳妥的表述是“交互整体在所有设定下显著；ENC 弹性偏低在 Python 的 8 个设定中都 p ≤ 0.013，但在 R 新增的最严格设定（7 个全部加入）中 p ≈ 0.08”。1 自由度的“中西部 vs 其他”对比（p = 3.2e-10，HC3）仍是更稳健的主结论。
3. **变量个数**：探针报告 §3.3 写“16 个预测变量（数值 3 + 类别 13）”，实际是 **17 个（数值 3 + 类别 14）**，汇总文档写的 17 是对的。
4. **类别标签**：SEWER = 3（“其他”，6 套）被并入标签为 septic 的组；FUEL = 4（燃油，1 套）并入 other；WAL1 = 6（混凝土砌块）并入 other。数值不受影响，R 与 proposal 中已改称“septic or other”等。
5. **Box-Cox 95% CI**：探针写 (−0.47, −0.375)，更细网格为 (−0.470, −0.372)。都不含 0，结论不变。
6. **Condition 1 的相关系数**：探针写 0.85，精确值 0.8445，两位小数应为 0.84。

## 4. 只在 R 中新增的检查

- 中西部对比的聚类 p 值改用 t(8) 参照分布：p = 5.9e-04（z 参照为 4.4e-08）。
- 7 个替代交互全部同时加入：交互 HC3 p = 1.3e-07；ENC − SA = -0.089（HC3 p = 0.076）。
- AIC 选出的模型（只删 hoa）作为最终模型的替代：交互 partial F p = 1.0e-9，HC3 p = 1.1e-10，结论不变。
